# Kimi-k2-Crew: Multi-Model Legal Analysis Orchestrator

## 🎯 Purpose
Collaborative AI system for analyzing legal documents, building case files through multi-stage research passes and persistent evidence tracking.

## 🚀 Quick Start

```powershell
# Run research automation
python run_ollama_research.py
```

## 🧠 How It Works

### 1. Multi-Pass Research (PROMPT.sql)
The system follows a 4-pass protocol:
- **PASS ONE**: Extraction of facts from background and argument.
- **PASS TWO**: Validation against the record.
- **PASS THREE**: Citation confirmation.
- **PASS FOUR**: Collection of additional supporting evidence.

### 2. LegalXML Integration
All findings are formatted in `LegalXML` using `Akoma Ntoso` tagging for structured data collection and judicial notice filing.

### 3. Automation Logic
The `run_ollama_research.py` script manages the state and timing between these passes, ensuring the model remains focused on the evidence-based facts provided in the documents.

## 🔧 Configuration
- **Model**: Defaulting to `qwen3:4b` via Ollama.
- **Delay**: Configurable timing between passes for processing/cooldown.
- **Individual Mode**: Stateless execution for fine-tuning individual stages.

## 🏆 Competitive Advantage
This system builds legal briefs based on hard evidence and strict duties, filtering out "AI fluff" and ensuring every claim is backed by the record.
